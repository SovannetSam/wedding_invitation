KHMER WEDDING WEBSITE

1. Extract this ZIP file.
2. Keep index.html and the photos folder together.
3. Open index.html in Chrome or Edge to view the website.
4. The gallery now shows six pictures. The couple portrait is also placed as the sixth gallery picture.
5. Use the Change Photos button on the website to replace photos or add more.

Internet is required for the Tailwind CSS and Google Fonts used by the original website.
